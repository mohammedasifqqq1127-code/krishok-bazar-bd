# কৃষক বাজার (KRISHOK BAZAR)

বাংলাদেশের কৃষক, মৎস্যচাষি ও ক্রেতাদের সরাসরি যুক্ত করার জন্য MVP ওয়েব অ্যাপ।

## চালানোর নিয়ম
1. Node.js 22 ব্যবহার করুন।
2. `npm install` চালান।
3. `.env.example` কপি করে `.env` তৈরি করুন।
4. `.env` ফাইলে কমপক্ষে ৩২ অক্ষরের শক্তিশালী `JWT_SECRET` দিন।
5. `npm start` চালিয়ে `http://localhost:3000` খুলুন।

## বর্তমানে যুক্ত ফিচার
- ক্রেতা ও কৃষক নিবন্ধন/লগইন
- বাংলাদেশের ৬৪ জেলার নির্দিষ্ট তালিকা
- পণ্য যোগ করা, খোঁজা এবং জেলা/ক্যাটাগরি দিয়ে ফিল্টার
- বিক্রেতার ফোনে সরাসরি যোগাযোগ
- ক্রেতার অর্ডার অনুরোধ
- কৃষকের স্থানীয় বাজারদর জমা (প্রথমে pending; অনুমোদনের পর প্রকাশ)
- অনুমোদিত স্থানীয় বাজারদর জেলা ও পণ্য দিয়ে খোঁজা
- পণ্যের বিরুদ্ধে রিপোর্ট জমা
- অ্যাডমিন API দিয়ে বাজারদর অনুমোদন/বাতিল এবং রিপোর্ট পর্যালোচনা

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- বাজারদর ফিচারটি কৃষকের জমা দেওয়া স্থানীয় তথ্য। এটি **সরকারি কৃষি বিপণন অধিদপ্তরের (DAM) দর নয়**।
- DAM-এর সরকারি দর স্বয়ংক্রিয়ভাবে আনার কোনো API এই প্রকল্পে সংযুক্ত বা যাচাই করা হয়নি।
- অ্যাডমিন API ব্যবহার করতে আগে থেকে `admin` ভূমিকার অ্যাকাউন্ট প্রয়োজন। সাধারণ নিবন্ধন থেকে কেউ অ্যাডমিন হতে পারে না। অ্যাডমিন অ্যাকাউন্ট নিরাপদভাবে সার্ভার/ডেটাবেস মালিককে তৈরি বা উন্নীত করতে হবে।
- পূর্ণ অ্যাডমিন ওয়েব প্যানেল, ছবি আপলোড স্টোরেজ, SMS OTP, bKash/Nagad, নোটিফিকেশন, ডেলিভারি, পরিচয় যাচাই ও স্বয়ংক্রিয় সরকারি বাজারদর সংযোগ এখনো নেই।
- এটি উন্নত MVP, এখনো production-ready নয়। লাইভ ব্যবহারের আগে নিরাপত্তা পরীক্ষা, ব্যাকআপ, গোপনীয়তা নীতি, অ্যাডমিন UI এবং hosting configuration সম্পন্ন করুন।

## API-এর নতুন রুট
- `GET /api/districts`
- `GET /api/market-prices?district=...&q=...`
- `POST /api/market-prices` (farmer login required)
- `POST /api/products/:id/report`
- `GET /api/admin/market-prices` (admin only)
- `PATCH /api/admin/market-prices/:id` (admin only; body: `{"status":"approved"}` বা `{"status":"rejected"}`)
- `GET /api/admin/product-reports` (admin only)
- `PATCH /api/admin/product-reports/:id` (admin only; body: `{"status":"reviewed"}` বা `{"status":"dismissed"}`)

`.env` কখনো GitHub-এ আপলোড করবেন না। `JWT_SECRET` কারও সঙ্গে শেয়ার করবেন না।
