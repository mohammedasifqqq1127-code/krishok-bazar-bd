# কৃষক বাজার (KRISHOK BAZAR)

বাংলাদেশের কৃষক, মৎস্যচাষি ও ক্রেতাদের সরাসরি যুক্ত করার জন্য প্রাথমিক ওয়েব অ্যাপ MVP।

## চালানোর নিয়ম
1. Node.js 20 বা নতুন সংস্করণ ইনস্টল করুন।
2. `npm install` চালান।
3. `.env.example` কপি করে `.env` তৈরি করুন।
4. `.env` ফাইলে কমপক্ষে ৩২ অক্ষরের এলোমেলো `JWT_SECRET` দিন।
5. `npm start` চালিয়ে `http://localhost:3000` খুলুন।

## MVP-তে আছে
- ক্রেতা ও বিক্রেতা নিবন্ধন/লগইন
- পণ্য যোগ করা, খোঁজা এবং জেলা/ক্যাটাগরি দিয়ে ফিল্টার
- বিক্রেতার ফোনে সরাসরি যোগাযোগ
- ক্রেতার অর্ডার অনুরোধ

## এখনো যুক্ত হয়নি
bKash/Nagad পেমেন্ট, SMS OTP, ছবি আপলোড স্টোরেজ, নোটিফিকেশন, ডেলিভারি, পরিচয় যাচাই, পূর্ণ অ্যাডমিন প্যানেল ও production deployment। পেমেন্ট চালুর আগে অনুমোদিত মার্চেন্ট অ্যাকাউন্ট এবং নিরাপদ gateway integration প্রয়োজন।

**সতর্কতা:** `.env` কখনো GitHub-এ আপলোড করবেন না। এই প্যাকেজ একটি MVP সোর্স কোড; এটি এখনো অনলাইনে ডেপ্লয় করা হয়নি এবং production-ready হিসেবে বিবেচিত নয়।
